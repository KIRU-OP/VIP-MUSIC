## 🖥️ Deploy on VPS / Local Machine

<table>
<tr><td>

**Step 1 — Clone the repository**
```bash
git clone https://github.com/KIRU-OP/VIP-MUSIC
cd VIP-MUSIC
```

**Step 2 — Run the setup script**
```bash
bash setup
```

**Step 3 — Configure your environment variables**
```bash
nano .env
```
📝 Fill in your variables → Save with `Ctrl+X` → `Y` → `Enter`

**Step 4 — Install tmux & start the bot**
```bash
sudo apt install tmux -y
tmux
bash start
```

**Step 5 — Detach the tmux session (keeps bot running)**
```
Ctrl + B, then D
```

</td></tr>
</table>
